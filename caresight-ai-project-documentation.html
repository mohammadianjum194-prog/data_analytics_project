1 Abstract

CareSight AI is a comprehensive, placement-ready healthcare analytics and patient readmission intelligence platform developed as the capstone project for the IBM SkillsBuild Data Analytics with AI Internship. The platform leverages a hospital patient dataset comprising 984 patient records across 15 attributes to deliver interactive exploratory data analysis, dynamic Plotly visualisations, and machine-learning-based readmission predictions.

Two classification models — Logistic Regression and Random Forest — are trained and evaluated using Accuracy, Precision, Recall, F1-Score, and ROC-AUC. The Streamlit-based web application provides five interactive pages: Dashboard, Patient Analytics, AI Insights, Model Performance, and About Project. All results and insights are derived entirely from the supplied dataset without fabrication.

2 Problem Statement

Hospital readmissions represent one of the most significant challenges in healthcare management. Key problems include:

  • Financial burden: Readmissions significantly increase the total cost of care for both patients and providers.
  • Resource strain: Repeated admissions occupy hospital beds and clinical staff, reducing capacity for new patients.
  • Quality indicator: High readmission rates indicate suboptimal treatment or discharge planning.
  • Limited predictive tools: Many facilities lack data-driven tools to identify high-risk patients before discharge.
  • Data silos: Patient data exists in fragmented systems, making holistic analysis difficult.

CareSight AI addresses these problems by building a unified analytics platform that processes patient admission data, identifies readmission patterns, and predicts individual patient readmission risk using machine learning.

5 Data Preprocessing

🧹 Data Cleaning

  • Column name whitespace removal via str.strip() — the Medication column had a trailing space in the raw CSV
  • All object-type columns stripped of leading/trailing whitespace
  • Admission_Date and Discharge_Date parsed from DD-MM-YYYY using errors='coerce'
  • Numeric coercion: Age, Length_of_Stay, Satisfaction, Total_Cost, Year_of_Admission cast to numeric

⚙️ Feature Engineering

  • Binary target: Readmission_Binary — Yes→1, No→0
  • Age group binning: pd.cut() with bins: <18, 18–35, 36–50, 51–65, 65+
  • Label encoding: LabelEncoder applied to Gender, Condition, Patient_State, Outcome, Insurance_Claimed; separate encoder per column stored for inference reuse
  • Exclusions: Patient_ID (identifier), Medication (leakage risk), raw dates (replaced by Length_of_Stay)

7 Machine Learning Methodology

🔵 Logistic Regression

  • Linear classifier — interpretable baseline
  • max_iter=1000, random_state=42
  • Outputs class label + probability

🌲 Random Forest

  • Ensemble of 100 decision trees
  • n_estimators=100, random_state=42
  • Handles non-linear patterns; provides feature importance

11 Installation & Run Instructions

Prerequisites: Python 3.12.x · pip (bundled with Python)

Step 1 — Place all files in one folder:

your-folder/
├── Anjum_CareSightAI.py          ← main app
├── Hospital Patient .csv         ← exact filename (space before .csv)
├── requirements.txt
└── README.md

Step 2 — Install dependencies:

pip install -r requirements.txt

Step 3 — Launch the application:

streamlit run Anjum_CareSightAI.py
The app opens automatically at http://localhost:8501. All five pages are accessible via the dark navy sidebar navigation.
